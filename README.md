# SimpleGripper – CAD Reconstruction

## About

This repository contains a CAD reconstruction of the [SimpleGripper – Open-source 2DOF Parallel Gripper](https://www.instructables.com/SimpleGripper-an-Open-source-Parallel-Gripper-With/).

The original project provided STL files, but editable CAD source files (STEP/SolidWorks) were not available. I recreated the geometry to make the design easier to inspect, modify, and manufacture.

## What's included

- Original geometry recreated in CAD.
- Editable CAD source files.
- STEP exports.
- STL files for 3D printing.
- Solidworks parts
